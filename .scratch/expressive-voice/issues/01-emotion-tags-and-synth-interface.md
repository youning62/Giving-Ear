# 01: 情绪标签与语音合成的情绪参数

**What to build:** 情绪词表（`emotions.py`）；文字模型后端把每句话开头的情绪标签剥掉并传给语音合成；`Synthesizer.synth(text, emotion)`；系统提示在使用情感引擎时要求标情绪、鼓励语气词。

**Blocked by:** 无

**Status:** done（2026-11-05）

## 完成记录
- `src/givingear/emotions.py`：9 种情绪（平静、开心、兴奋、温柔、关切、难过、惊讶、生气、俏皮）及对应的语气指令；`parse_emotion` 把句首标签剥掉，词表外的方括号（例如 [小王]）保留。
- `TextChatBackend`：每句话先解析情绪再合成；没标签沿用本轮上一句的情绪，新的一轮不沿用；页面上和朗读里都没有标签。`Synthesizer.synth(text, emotion)`。
- 系统提示：情感引擎下要求每句话标情绪、语气有起伏、适当用语气词；本机引擎不要求。
- 顺手修了一个旧测试里的竞争（只等到第一个说话人就收尾）。
