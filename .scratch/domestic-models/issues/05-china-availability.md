# 05: 国内可用性：模型文件下载

**What to build:** 本地模型（VAD、声纹、转写）支持下载镜像前缀（环境变量 `GIVINGEAR_DOWNLOAD_MIRROR`），下载失败时给出清楚的中文提示，说明怎么手动下载并放到哪个目录；README 补充国内使用说明。

**Blocked by:** 无

**Status:** done（2026-11-04）

## 完成记录
- `models.py`：`GIVINGEAR_DOWNLOAD_MIRROR` 镜像前缀；下载失败给出模型名、原始地址、目标目录和手动下载的办法，不留半截文件；已在目录里的文件直接使用。`ModelDownloadError` 是 `ConfigError` 的子类，会显示在网页上。
- 第一次开始监听时加载/下载本地模型放在线程里做，不卡住网页服务。
- **没做：** 没有找到可靠的国内镜像地址，所以没有内置任何镜像，需要用户自己提供前缀；还没有把模型文件放到国内可直连的存储上。


- [x] 测试：设置镜像前缀后，下载地址被加上前缀
- [x] 测试：下载失败时错误消息包含模型名、原始地址和目标目录；失败不会留下半截文件
