# 01: 文字模型后端（转写 → 模型 → 语音合成）

**What to build:** 新的 `VoiceBackend` 实现 `TextChatBackend`：每句本地转写带着说话人名字送给文字模型；流式接收回复，按句子切开交给语音合成再播放；支持"[沉默]"、工具调用（命名、登记）、被打断。协议新增 `send_transcript`、`interrupt`（Gemini 后端里是空操作）。

**Blocked by:** 无

**Status:** done（2026-11-04）

## 完成记录
- `src/givingear/chat_backend.py`：`TextChatBackend`。每句转写以"[小王]：……"送给文字模型，回复按句子切开逐句合成播放；"[沉默]"不播放但留在上下文里；同一时间窗内的连续发言只回复一次；工具调用（命名、登记）支持，等工具结果期间到达的背景说明会延后加入，保证"工具调用 → 工具结果"紧挨着；有人开口时取消回复并发 interrupted；模型报错发 error 事件、下一句话可继续；历史超长从最早的裁掉，且不会从工具结果开头。
- 协议新增 `send_transcript`、`interrupt`；Gemini 后端里是空操作；`Session` 每句话转写完成后调用前者、每次有人开口调用后者。
