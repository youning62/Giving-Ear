# 国内可用的模型（文字模型 + 本地语音），与 Gemini 并存

**Status:** v1 完成（2026-11-04），待用真实的 DeepSeek 密钥和麦克风试用

## 背景

网站可能在国内运行，Gemini 在国内很可能连不上，所以必须有国内可用的模型。同时保留 Gemini，由用户在页面里自己选。

## 已确认的决策（用户，2026-11-04）

- 接入国内模型是必要的；Gemini 版本继续保留；用户可以在设置里选择用哪个。

## 设计

- Gemini Live 是**原生语音模型**（音频进、音频出）。国内主流模型（包括 DeepSeek）是**文字模型**，没有音频输入输出。所以新增一种后端：
  `麦克风 → 本地转文字（SenseVoice，已按说话人分好）→ 文字模型 → 语音合成 → 扬声器`
- 做成**通用的"OpenAI 兼容接口"后端**：DeepSeek 是预设（`https://api.deepseek.com`、`deepseek-chat`），另提供"自定义"：填地址、模型名、密钥，就能接通义、智谱、月之暗面等任何兼容接口的国内模型。
- 每句话由本地转成文字，带着说话人名字（"[小王]：……"）发给模型，所以说话人归属比 Gemini 更准。
- 什么时候说话：靠系统提示——不是对 AI 说的话，模型只回复固定的"[沉默]"，我们丢掉这条回复不播放。
- 有人开口就打断：取消正在生成的回复、停止播放。
- 语音合成：先用 macOS 自带的 `say`（离线、免费、有点机械），合成接口可替换，以后换本地 TTS 或云端 TTS。
- 密钥各存各的（`~/.config/givingear/env`，权限 600）；选择哪个提供商、模型名等非密钥设置存在同目录的 `settings.json`。

## 已知取舍

- 延迟比 Gemini 原生语音高：转文字 + 模型 + 合成三段串联。
- 模型只看得到文字，听不到语气、笑声；本地转文字偶尔听错。

## 国内可用性（要单独处理）

- 本地模型文件（VAD、声纹、转写）目前从 GitHub Releases 下载，国内可能很慢或不通。需要支持镜像前缀，并在文档里写明手动下载的位置。
