# 05: 本地网页：注册、登录、声纹管理

**What to build:** 在本地网页里增加"账号"区：注册账号、登录、退出，登录后可以查看、改名、删除声纹档案，并用这个账号开始/停止监听。本地服务只监听 127.0.0.1，登录后用随机会话令牌（仅存内存），密码不落盘、不出现在日志里。

**Blocked by:** 01, 03, 04

**Status:** done（2026-11-04），**未做：网页里直接开始/停止监听**

## 完成记录
- `src/givingear/webapi.py`：页面和账号接口（注册、登录、退出、列出/改名/删除声纹）。令牌只在内存里；校验 Host 和 Origin；POST 必须是 JSON；同一账号连错 5 次锁定 5 分钟；登录失败不透露是用户名还是密码错。只监听 127.0.0.1。
- 网页：header 的"账号"按钮打开弹窗，登录/注册，登录后看到声纹档案并可改名、删除。
- 会话里登记前会先 `vault.reload()`，网页改动不会被覆盖。
- **没做：** 网页里"开始/停止监听"。会话仍然由命令行 `givingear --account 名字 --web` 启动，网页是同一账号的管理和实时查看界面。要让网页控制麦克风，需要把会话生命周期搬进服务进程，是一个单独的改动，需要另开一张票。
- 对话弹窗只在无头 Chrome 里确认了页面加载正常，没有自动化地点过弹窗里的按钮；接口本身有 13 个测试。


- [x] 测试：本地接口——注册、登录（错误密码返回 401）、列出档案、删除档案、退出
- [x] 测试：未登录访问档案接口返回 401；令牌只在内存里，服务重启后失效
- [x] 测试：服务只监听 127.0.0.1，且校验 Origin，避免其他网站用浏览器向本地服务发请求
- [x] 网页：登录/注册表单、声纹档案列表（改名、删除、"忘记我"）
