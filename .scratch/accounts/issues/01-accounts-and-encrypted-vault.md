# 01: 账号与加密声纹库

**What to build:** 本地账号存储（`accounts.py`）：创建账号、用密码登录、修改密码、删除账号；登录后得到一个解锁的声纹库，可以增加、改名、删除、列出声纹档案并保存。声纹库用密码派生的密钥加密存储，只含名字、别名、特征向量、登记时间、声纹模型名。

**Blocked by:** 无

**Status:** done（2026-11-04）

## 完成记录
- `src/givingear/accounts.py`：`AccountStore`（创建/登录/改密码/删除）和 `Vault`（增加/改名/删除/保存）。scrypt 派生 64 字节：前 32 字节做 AES-256-GCM 密钥，后 32 字节的 SHA-256 做密码校验值；用户名做附加认证数据，换了目录就解不开。原子写入（临时文件 + `os.replace`）。
- 测试 `tests/test_accounts.py`（15 个）覆盖了本票所有验收项，另外覆盖了篡改检测。
- 用户名不区分大小写，存成小写；允许中文。


- [x] 测试：创建账号后能用正确密码登录；错误密码和不存在的账号分别给出清楚的错误
- [x] 测试：用户名只允许字母、数字、下划线、连字符（含中文），不能含路径分隔符或 `..`；用户名不区分大小写，不能重名
- [x] 测试：增加的档案重新登录后还在，特征向量逐位一致
- [x] 测试：硬盘上的声纹库文件里读不到名字和别名（已加密）；账号记录里没有密码
- [x] 测试：改密码后旧密码失效、声纹库不丢；删除账号会彻底删掉目录
- [x] 测试：保存中途出错不会破坏已有声纹库（原子写入）
