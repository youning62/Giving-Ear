# 02: 会话接入声纹库

**What to build:** 用账号登录后启动会话，声纹库里已登记的人在第一次开口时就以名字被认出，不再是"说话人 N"；他们进入"房间名单"，AI 能按名字称呼。已登记的人不会被悄悄更新声纹库（只有明确登记才会写入）。不登录也能用，全部人都是临时的"说话人 N"。

**Blocked by:** 01

**Status:** done（2026-11-04）

## 完成记录
- `Session(vault=...)`：已登记的人以 `u1`、`u2`… 为编号载入，第一次开口就被认出；会话开始就发房间名单（"小王（已登记）"）和 `account_loaded` 事件。
- 会话里只改内存副本，不会写声纹库（有测试比较文件字节）。
- 声纹库的模型名和当前模型不同：发错误事件"需要重新登记"，不使用旧声纹。

- [x] 测试：会话开始时房间名单里就包含已登记的人
