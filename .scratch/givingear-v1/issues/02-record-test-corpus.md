# 02: 录制多人测试语料

**What to build:** 一组供自动化测试和准确率验证使用的 WAV 测试语料，由开发者和至少两位朋友在真实房间里，用 Mac 的麦克风录制。包括：每个人用于注册的语音样本（约 20–30 秒），以及若干段多人对话。对话需覆盖中文、英文、中英混说、两人交替说话、两人重叠说话，以及一位"陌生人"（不提供注册样本）。每段对话附一份标注，写明每个时间段是谁在说话。录音只用于本地测试，参与者都应知情并同意。参考规格：`.scratch/givingear-v1/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] 至少 3 人，每人一段注册样本（陌生人除外）
- [ ] 至少 5 段多人对话，每段 1–3 分钟，覆盖上述全部情况
- [ ] 每段对话都有说话人时间段标注（开始时间、结束时间、说话人、是否重叠）
- [ ] 格式统一（单声道，采样率与 sherpa-onnx 模型要求一致），并记录录音设备和环境
- [ ] 明确这批语料能否放进开源仓库；不能放的话，放在不会提交到仓库的本地目录
