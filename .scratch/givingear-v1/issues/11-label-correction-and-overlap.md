# 11: 标签更正与重叠标注

**What to build:** 说话人识别更可靠，包含两部分：
- **更正**：开口约 1 秒的初判之后，如果后续音频改变了判断（初判错了，或者一句话中途换了人），核心发出"说话人更正"事件，并通知后端插入更正文字，命令行界面上对应的标签随之更新。
- **重叠**：检测到两人同时说话时，只标主说话人（音量最大或说话时间最长的那个），并注明"有重叠"。

阈值和判断时机采用 03 的结论。参考规格：`.scratch/givingear-v1/spec.md`。

**Blocked by:** 03（验证 1 秒判断准确率），05（最小通路）

**Status:** ready-for-agent

- [ ] 测试：语料中一句话中途换人时，核心发出更正事件，假后端收到更正文字
- [ ] 测试：两人重叠说话的语料片段，事件中带"有重叠"标注，并标出主说话人
- [ ] 测试：初判正确时，不发出多余的更正事件
- [ ] 命令行界面能显示更正后的标签和"有重叠"标注
