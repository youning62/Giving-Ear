# 12: 出错提示

**What to build:** 常见问题都给出清楚的中文提示，告诉用户该怎么修：
- 缺少或无效的 Gemini API 密钥：说明从哪里申请，以及放在环境变量还是配置文件
- 没有麦克风权限：说明去 macOS 系统设置的哪里开启（采用 04 的结论）
- 网络断开：提示连接已断开
- 达到会话时长上限：提示用户重新启动（第一版不自动重连）

这些状态同时通过事件流以"连接状态 / 错误"事件发出。按 Ctrl+C 时干净退出：关闭会话，清空内存缓存。参考规格：`.scratch/givingear-v1/spec.md`。
