# 03: 验证：开口约 1 秒判断说话人的准确率

**What to build:** 一个最小验证脚本：用 sherpa-onnx 配合 3D-Speaker CAM++ 声纹模型，在 02 的测试语料上，测量"开口约 1 秒时的初判"和"整句说完后的判断"两种情况下的说话人识别准确率。同时找出"判为陌生人"（与所有档案都不匹配）的相似度阈值，并测出单次计算声纹的耗时。结论写在本票末尾的"结论"小节，供 05 和 11 采用。参考规格：`.scratch/givingear-v1/spec.md`。

**Blocked by:** 02（录制多人测试语料）

**Status:** ready-for-agent

- [ ] 给出 1 秒、1.5 秒、2 秒初判和整句判断的准确率对比
- [ ] 给出推荐的陌生人阈值，以及它对应的误认率和漏认率
- [ ] 测出在 Apple Silicon 上单次计算声纹的耗时
- [ ] 评估中英混说和重叠片段对准确率的影响
