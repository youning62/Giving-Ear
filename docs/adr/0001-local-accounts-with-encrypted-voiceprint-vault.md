# 0001: 本地账号 + 加密声纹库

**Status:** accepted（2026-11-04）

**Context:** 声纹是生物特征数据，不能更换，泄露后果严重；产品以后要接服务器，成为正规平台，但现在只有本机。

**Decision:**
- 账号是"空间"，名下存多人声纹；用户名 + 密码登录。
- 声纹库用 scrypt 派生的密钥做 AES-256-GCM 加密；不保存密码，不设恢复后门。
- 声纹库里只存特征向量和名字，不存音频；特征向量记着所用模型名，模型换了就不能用。
- 存储层与登录逻辑放在 `accounts.py`，会话和界面只依赖它的接口，以后换成服务器实现时界面不用改。

**Consequences:** 忘记密码就丢声纹，需要重新登记；换声纹模型要让所有人重新登记。
